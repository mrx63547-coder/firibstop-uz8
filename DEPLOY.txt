FiribStop UZ 2.5.0 — Professional · Signature UI, light/dark themes, regional map

Render:
- Runtime: Node
- Build command: npm install
- Start command: npm start
- Health check: /api/health

После обновления:
1. Загрузите содержимое проекта в репозиторий GitHub.
2. Дождитесь успешного деплоя Render.
3. Откройте сайт и нажмите Ctrl+Shift+R.
4. Проверьте переключение светлой/тёмной темы и мобильную навигацию.
5. Откройте «Карта киберугроз Узбекистана» и убедитесь, что карта доступна.
   При блокировке картографических сервисов подложка может не загрузиться,
   несмотря на готовую разметку карты.
6. Проверьте индикатор «Онлайн / Офлайн» в верхней панели.

Service Worker: v21.
Свежие новости и картографическая подложка требуют интернет.
